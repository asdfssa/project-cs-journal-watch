การนับคำขอต่อวินาทีของ Scopus key

จำลองการทำงานของ getNextKey() และ _isThrottled() ใน ScopusProxyService.js (ไม่ได้ยิง Scopus จริง ไม่แตะไฟล์ใด ๆ)

แต่ละจุด = 1 ครั้งที่ key นั้นถูกเลือกไปใช้ (ค่าใน recentRequestTimestamps) ขวาสุดคือ "ตอนนี้" จุดเลื่อนไปซ้ายตามเวลา นับอยู่ (ไม่เกิน 1 วินาที) เก่าเกิน 1 วินาที (ไม่นับ — โค้ดจริงจะลบทิ้งตอน filter)
3 วินาทีก่อน1 วินาทีก่อนตอนนี้
บันทึกการตัดสินใจของ getNextKey() (attempts = ดู key ไปแล้วกี่ตัวในคำขอนี้)

ติ๊ก "ถูกพัก" ที่ key ใดก็ได้เพื่อจำลองกรณีได้ 429 (_isLocked) — ระบบจะข้าม key นั้นเสมอ ส่วนโควตารายสัปดาห์ไม่ได้จำลองในหน้านี้
